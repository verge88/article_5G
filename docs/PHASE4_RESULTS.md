## Научная постановка

После получения подлинных измерений Open5GS отдельно формировались
недостоверные отчёты локального контрольного агента: заведомо ложное
состояние SMF, ложное сообщение об исходе PDU или оба поля. Фальсификация
осуществлялась **после измерений**, а не внутри работающей NF.

Для каждого реально наблюдаемого PDU-исхода сгенерированы пара
отчётов: правдивый и один подменённый. В тесте — 24 правдивых и 24
подменённых отчёта, из которых по восемь в каждом виде искажения.
Сообщение о ложном успехе содержит правдоподобную задержку, выбранную
из реально измеренных успешных PDU-сессий. Это убирает тривиальное
локальное противоречие между заявленным успехом и нулевой задержкой.

**Разделение без пересечений развёртываний:** train=101,
validation=202, test=303. Порог определялся по валидационным
правдивым событиям с целевым FPR 5%, а затем был зафиксирован.
Использована сопоставимая Random Forest во всех абляциях.
Метка искажения, фаза, номер прогона и ID среды НЕ являются
признаками модели.

## Итоговые тестовые показатели

| Модель | Recall искажённых отчётов | FPR правдивых | F1* |
|---|---:|---:|---:|
| RF: только локальные показатели | 16/24 = 66,67 % | 0/24 = 0 % | 0,800 |
| RF: локальные + КИЕ | 24/24 = 100 % | 0/24 = 0 % | 1,000 |
| RF: + сетевые NRF/AMF | 24/24 = 100 % | 1/24 = 4,17 % | 0,980 |
| RF: + привилегированный Docker-наблюдатель | 24/24 = 100 % | 1/24 = 4,17 % | 0,980 |
| Правило: только несогласованность КИЕ | 16/24 = 66,67 % | 0/24 = 0 % | 0,800 |
| Правило: КИЕ или независимый Docker-наблюдатель | 24/24 = 100 % | 0/24 = 0 % | 1,000 |

*F1 рассчитан на искусственно сбалансированной выборке.
У оператора компрометации встречаются с иной частотой.

Добавление КИЕ к локальным показателям позволило обнаружить восемь
дополнительных подмен (+33,33 процентного пункта Recall) без увеличения
измеренного FPR. Все восемь пропусков локального классификатора относятся
к согласованной фальсификации сразу двух локально сообщаемых состояний.

**Отрицательный результат:** добавление NRF/AMF и привилегированного
свидетельства Docker не увеличило Recall относительно КИЕ, но привело
к одной ложной тревоге. Утверждение, будто увеличение иерархии
неизменно улучшает обнаружение, экспериментом НЕ подтверждено.

## Главные ограничения

1. Это проверка **искусственной фальсификации отчётности по результатам
   реальных PDU-процедур**, НЕ реальный взлом SMF и НЕ изменение
   HTTP/2/Nsmf-сообщений атакующим.
2. Независимый показатель КИЕ конструируется как абсолютная разность
   между ложным заявлением и реально измеренным итогом процедуры.
   Обнаружение этой разницы частично обусловлено самим способом
   формирования «атаки» и не доказывает мировую научную новизну.
3. Привилегированное Docker-состояние — лабораторная истина, а не
   стандартный независимый источник 3GPP для оператора 5G.
4. Тест: лишь 24 реальные процедуры из одного развёртывания, каждая
   образует связанную пару «правдивый–подменённый»; оценки сильно
   неопределённы. 100 % Recall не означает нулевую истинную ошибку.
5. Развёртывания используют одно программное семейство. Реальных
   атак с тонкой сменой семантики при работающем SMF не выполнялось.

## Вывод для научной статьи

Реальные измерения 5G подтвердили возможность сопоставлять независимый
результат UE/PDU с отчётом контролирующего агента. При введённой
согласованной фальсификации локальных показателей модель только
локальной отчётности пропустила восемь случаев, а КИЕ позволили их
обнаружить.

Строгую научную новизну следует связывать не с Random Forest как
таковым, а с конструкцией независимых КИЕ, условиями наблюдаемости
скрытого нарушения, допустимыми временными окнами, моделью доверия
к наблюдателям и проверкой устойчивости при компрометации этих
наблюдателей.
