# Этап 2 — исследовательский протокол и пределы доказательств

## A. Проверка работоспособности КИЕ в настоящем Open5GS 5G Core

Workflow: [real-open5gs-sbi](../.github/workflows/real-open5gs.yml).

Используется публичное лабораторное развёртывание Open5GS (версии окружения
зафиксированы SHA upstream и digest контейнерного образа в артефакте запуска).
Запускаются реальные NRF, SCP, AUSF, UDM. Контрольная операция — допустимый
HTTP/2 GET Nnrf_NFDiscovery к NRF с параметрами target-nf-type=AUSF,
requester-nf-type=AMF.

**КИЕ данного этапа** — запись контрольного агента (идентификатор опроса,
время, HTTP/2, код ответа, RTT, число зарегистрированных NF). Это
экспериментальная измерительная абстракция, а не новый формат сообщения
3GPP; опрос производится без изменения абонентских данных.

Скрипт [src/real_sbi.py](../src/real_sbi.py) должен вернуть не менее 80%
успешных ответов HTTP/2 200 с найденным экземпляром AUSF. Иначе workflow
завершится ошибкой. Опросы и агрегации сохраняются в артефакте Actions.
Отдельно сохраняется живое состояние контейнеров NRF и AUSF, версия
развёрнутой конфигурации и digest контейнера.

**Что это подтверждает:** применимость идеи активного опроса к реальному
сервису 5G SBA, наблюдаемость ответов и измеримость задержек.

**Что это пока НЕ подтверждает:** работу с PDU Session Establishment,
выявление скомпрометированного SMF, причинную независимость показаний,
транзит КИЕ по тому же маршруту, что и бизнес-сигнализация,
пропускную способность и эффекты в работающей операторской сети.

## B. Влияние недоверенной телеметрии (синтетический эксперимент)

Workflow: [research-experiments](../.github/workflows/experiments.yml).
Код: [src/robustness.py](../src/robustness.py).

После обучения классификатора на условно доверенных данных последовательно
подменяются признаки в тестовой части, которую модель ранее не видела:

1. witness_suppression — компрометация двух признаков согласованности.
2. observer_capture — дополнительно подмена зональной независимой оценки.
3. total_blinding — подмена всех перечисленных источников, включая КИЕ.
4. false_testimony — фабрикация сообщений о нарушениях у нормальных узлов.

Доля целевых измерений для каждой стратегии составляет 0, 25, 50, 75, 100%.
Стратегии конструируются по истинным меткам сценария: это «оракульная»
модель сильного нарушителя, а не реальный перехват узла. Порог
классификатора фиксирован по исходной валидационной выборке с целевым FPR
1%, не подбирается заново после компрометации. Публикуются тестовые FPR,
Recall по скрытой компрометации, F1, AUROC, AUPRC.

## Правила интерпретации

- Не объединять синтетический Recall со статистикой HTTP/2 лабораторного стенда.
- Не называть результат теста реального NRF «обнаружением SMF-компрометации».
- Качественное улучшение в synthetic не доказывает глобальный научный приоритет.
- 4 независимых тестовых зерна — мало для строгих узких доверительных интервалов.
- Прежде чем заявлять о полной экспериментальной апробации методики,
  необходимо построить контролируемый стенд AMF–SMF–UPF + UERANSIM с
  регистрацией UE и созданием PDU-сессии, получить трассировки
  Nsmf_PDUSession и журналы независимых контрольных агентов, провести
  санкционированный сценарий изменённого результата процедуры и повторить
  абляцию без прямого попадания метки в генерируемые признаки.
