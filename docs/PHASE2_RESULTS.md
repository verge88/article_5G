**Научный смысл:** замаскированная компрометация достоверно распознаётся в
синтетическом эксперименте только при сохранении достаточной
независимой контрольной информации. При целенаправленной подмене
рассогласований детектор закономерно теряет полноту; поддельные показания
могут резко повысить FPR.

**Ограничения:** вредоносные строки выбираются по истинным меткам,
злоумышленные значения синтетически задаются вручную, источник-
наблюдатель первоначально считается надёжным. Это чувствительность
модели к подмене входных признаков, а не эксплуатационное тестирование
реального нарушителя. 4 независимых тестовых зерна — мало для
статистического обобщения.

## Предварительный научный вывод

Гипотеза «чем больше независимых свидетельств, тем лучше обнаружение»
не может применяться без уточнения **модели доверия**: дополнительный
контрольный агент может стать источником ложных тревог. Следующая
математическая задача — оценка достоверности источников и
отказоустойчивое объединение независимых (желательно >=3) наблюдателей
при формально заданном максимальном числе недоверенных источников.

Это предложение направления будущей научной новизны, не утверждение
о доказанной стойкости к Byzantine-нарушителю.
