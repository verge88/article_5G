модели к подмене входных признаков, а не эксплуатационное тестирование
реального нарушителя. 4 независимых тестовых зерна — мало для
статистического обобщения.

## Предварительный научный вывод

Гипотеза «чем больше независимых свидетельств, тем лучше обнаружение»
не может применяться без уточнения **модели доверия**: дополнительный
контрольный агент может стать источником ложных тревог. Следующая
математическая задача — оценка достоверности источников и
отказоустойчивое объединение независимых (желательно >=3) наблюдателей
при формально заданном максимальном числе недоверенных источников.

Это предложение направления будущей научной новизны, не утверждение
о доказанной стойкости к Byzantine-нарушителю.

## Эксперимент C. Реальный аварийный отказ AUSF и временное рассогласование с NRF

- Успешный GitHub Actions run: https://github.com/verge88/article_5G/actions/runs/38134803197
- Репозиторий содержит исполняемый протокол: `src/real_fault.py`.
- В отдельной лабораторной конфигурации после начальных 40 успешных
  HTTP/2 GET Nnrf_NFDiscovery контролируемо завершён процесс AUSF через
  Docker SIGKILL, затем восстановлен.
- `docker inspect ausf State.Running` обеспечивает независимую лабораторную
  истину о состоянии процесса; HTTP/2 NRF discovery — отдельную сетевую
  информацию, воспринимаемую потребителем SBI.
- Во время остановки AUSF: **38** измерений,
  каждый раз Docker достоверно показывал `State.Running=false`.
- В **14/38** контрольных опросах NRF ещё сообщал о зарегистрированном AUSF
  (`nfInstances` содержит один профиль). Это не доказательство злоупотребления:
  NRF может нормативно ожидать истечения heartbeat/валидности записи.
- Последний положительный discovery наблюдался на отметке **4.3291 с**,
  первый отрицательный — **4.6493 с** по часовому отсчёту сценария,
  начинающемуся ПЕРЕД предварительной проверкой и SIGKILL.
  Поэтому граница наблюдаемого перехода локализована между этими опросами,
  но НЕ является точной длительностью от получения ядром сигнала SIGKILL.
- В **38** измерениях восстановления контейнер активен, NRF снова
  возвращает зарегистрированный AUSF.
- Новый артефакт: `real_fault_probes.csv`, `real_fault_summary.json`,
  и файлы исходных версий и точных данных HTTP/2.

**Научное значение:** подтверждено, что реальная иерархическая система
наблюдения может получать два различающихся свидетельства о состоянии
одной сетевой функции и измерять рассогласование. Один разовый
аварийный отказ НЕ подтверждает компрометацию или закономерную
длительность рассогласования; требуется серия повторов при разных
heartbeat, нагрузках и числе NF.

**Проверяемая гипотеза для следующей модели:** учитывать время, которое
нормально требуется NRF для удаления устаревшей регистрации, прежде
чем считать противоречие подозрительным:

`D_i(t) = |A_i(t) - R_i(t)|`,

где `A_i(t)` — доверенная независимая оценка фактической доступности,
`R_i(t)` — сведения discovery, а аномальность определяется по длительности
устойчивого расхождения, а не только по мгновенному `D_i=1`.
Наблюдение одного отказа не позволяет пока определить адекватный порог.
