# Стандартизованные механизмы корреляции 5G SBI

Согласно 3GPP TS 29.500 V18.9.0, разделам 5.2.3.3.4 и 6.13.2, заголовок `3gpp-Sbi-Correlation-Info` может использоваться для соотнесения сообщений с одним пользовательским контекстом, если функция и настройки сети его поддерживают. Раздел 6.13.3 описывает `3gpp-Sbi-NF-Peer-Info` для информации о взаимодействующих сетевых функциях.

Первичный источник: https://www.etsi.org/deliver/etsi_ts/129500_129599/129500/18.09.00_60/ts_129500v180900p.pdf

Эти средства известны по стандарту. Сама идея присваивания идентификатора взаимодействия не является научной новизной. Возможным самостоятельным вкладом может быть модель независимого контроля достоверности событий и принятия решения при недостаточном доверии к источникам контрольных признаков.

На шестом этапе наличие этих заголовков в Open5GS не проверялось: реализовано только временное сопоставление и связывание ответа с HTTP/2-потоком. Корреляционная информация, которая могла бы содержать абонентские данные, не должна попадать в открытые артефакты.
